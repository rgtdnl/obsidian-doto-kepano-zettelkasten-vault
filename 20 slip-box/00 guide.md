# 20 Slip-box: the main compartment

**Purpose:** main notes — single ideas, self-contained, connected to everything related. This is the heart of the zettelkasten. Hub notes, structure notes, and the keyword index also live here as high-level views.

The book: at its most basic, a main note should have a single idea and a link to another idea stored in your zettelkasten.

## What lives here
- **Main notes:** the ideas themselves. Title is the claim, written as a full sentence (category [[main]]).
- **Hub notes:** entry points listing where trains of thought start (category [[hub]]).
- **Structure notes:** places to unpack and organize a train of thought semantically (category [[structure]]).
- **Keyword index:** the oracle — keywords pointing at a few notes each (category [[index]]).

## Rules
- **One idea per note.** If "but" or "however" shows up while writing, split the note.
- **Title = claim:** "Not all apples are edible", not "Apples and edibility".
- **Every main note gets an alphanumeric ID** (folgezettel): first note `1.1`; related ideas branch (`1.1a`, `1.1a1`); new ideas get the next number (`1.2`); unrelated ideas start a new section (`2.1`). IDs are street addresses, not a tree. Never renumber, there are no occupied slots.
- **Link with context.** State why each "see" link was made. Link dumping assumes future-you remembers; future-you won't.
- **Contradictions stay.** A new idea that refutes an old one becomes a new note that links to and challenges the old one. Nothing is edited or deleted to "fix" disagreement.
- **Notes need not be perfect.** They don't need to represent your current thinking. Value is decided later, in relation to other notes. One to ten minutes per note.
- **No categories, no folders by topic.** The slip box grows bottom-up. Section headings can be added later as labels only, never as places new notes "should" go.
- Never put fleeting, project, or raw notes in here. Main notes only. Never archived.

## Weekly action
1. Process the inbox: capture → main note, sleeping, or delete.
2. Write 3-6 main notes (Luhmann averaged 6; fewer is fine).
3. For each: does it extend, contradict, or raise what exists? What questions does it trigger?
4. Link it with context. Check backlinks on everything you touch. Follow threads, don't file.
5. Long ID strings = developed trains of thought = candidates for writing.
