# The value of an idea is determined by its relationships

A single idea, on its own, has no fixed worth. Its value is decided in relation to the other ideas it touches: what it extends, contradicts, or raises. This is why an unconnected note is a dead note; it cannot be found, recalled, or reused until something else points at it.

> Every note is an element which receives its quality only from the network of links and back-links within the system. — Luhmann, in Doto, *A System for Writing*, p. 60
